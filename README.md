# Spark Chamber

> Team Dawson SPARKS

Dawson HEP Spark Chamber. A Beamline for Schools (BL4S) 2026 competition proposal submission.

Proposal:
- Paper [HERE](docs/proposal.pdf).
- Video [HERE](https://youtu.be/4N5ECrgIn5k).

## Project Structure
- Simulation
    - GEANT4 azimuthal simulations: [Github](https://github.com/Dawson-HEP/geant4-pvt-sim/tree/gcr_sim), `gcr_sim` branch
- Hardware: [./hardware](./hardware/)
    - Source Trigger Unit (STU): [`./hardware/source_trigger_unit`](./hardware/source_trigger_unit/)
    - High voltage probe: [`./hardware/high_voltage_probe`](./hardware/high_voltage_probe/)
- Acquisition
    - *opentrig* DAQ: [Github](https://github.com/Dawson-HEP/opentrig)
- Sound Triangulation
    - Sound triangulation system: [`./tracking`](./tracking/)
    - ML Acoustic Computation: [Github](https://github.com/Dawson-HEP/AcousticDETR)
